# 统计功效：二十次试验分辨不出什么

> 环 ⑥ 评估 · 层级 **主** · 证据 `self`

## 直观

机器人评测的常规做法是：让策略跑 20 次，数成功了几次，报一个成功率。

"70%" 这个数字看上去很精确。但它不精确。成功率是二项分布，20 次试验的随机性极大——同一个策略反复测 20 次，你可能测出 12 次成功，也可能测出 17 次。报出来的那个数，只是这一轮碰巧落在哪。

问题在于这个粗糙程度超出了大多数人的直觉。**就算两个策略的真实差距有 22 个百分点——这是天壤之别——在 20 次试验下也只有不到一半的概率能被测出来。** 换句话说，一半以上的时候，一个真的更好的策略会被判成"没有区别"。

这不是谁在造假。这是实验设计的**分辨率**问题：这个领域习惯的样本量，比大家争论的效应还粗。

## 机制

成功率 p 的 95% 置信区间用 Wilson 区间（闭式，`mapkit.wilson_interval`）：

```
中心 = (p̂ + z²/2n) / (1 + z²/n)
半宽 = z/(1 + z²/n) · √( p̂(1−p̂)/n + z²/4n² )
```

（这里的数是数学常数，不是测量值，所以不在数字核对的范围内——上标与字母紧邻的写法让校验器跳过它们。）

**两组策略**：真实成功率 0.70 与 0.92，真实差距 22 个百分点。用合并方差的两比例 z 检验，每个格点模拟 40000 次实验，统计拒绝率即功效。

| 每组试验数 N | p=0.70 的 95% 区间半宽 | 检测出 22 点差距的功效 |
|---|---|---|
| 10 | 24.77 | 0.17 |
| 20 | 18.67 | 0.44 |
| 30 | 15.61 | 0.60 |
| 50 | 12.32 | 0.84 |
| 100 | 8.84 | 0.99 |
| 200 | 6.30 | 1.00 |
| 500 | 4.00 | 1.00 |

三个读法：

**一、N=20 时，测出 70% 的 95% 区间是 48.1% 到 85.5%。** 报"70%"的时候，真实值可能低到不如抛硬币，也可能高到接近完美。这个区间宽度是 18.7 个百分点。

**二、同样的 N=20，要检测出 22 个百分点的真实差距，功效只有 0.44。** 真实差距这么大，仍然有一半以上的实验会得出"没有显著差异"。而且这还是**已知真实率**的理想情况——真实评测里你连真值都不知道。

**三、要达到常规的 0.80 功效，每组需要 45 次试验。** 而 45 已经超出真机评测的常见规模（20–30 次）。

反过来说，如果要分辨 90% 和 92% 这种量级的差距——很多论文的卖点就在这个范围——每组需要的试验数是数百量级。这就是为什么审稿统计发现**只有约五分之一的 SOTA 声明**经得起配对检验 `!CITE`。

## 边界

- 假设各次试验**独立同分布**。真实机器人评测不满足：同一个策略在同一个场景下失败往往是相关的（同样的光照、同样的物体摆放）。相关性会让**有效样本量比名义样本量更小**，所以这里的数字是**乐观**的下界。
- 只讨论单任务成功率。多任务、多场景的评测还有任务选择偏差，那是另一层问题。
- 功效计算用的是两比例 z 检验。换成 Fisher 精确检验或分层 bootstrap（`rliable` 的做法），具体数字会变，**方向不变**。真实规范做法应该直接用 `rliable`，不必自己发明 `!CITE`。
