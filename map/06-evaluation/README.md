# ⑥ 评估

> 这一环的产出不是"模型多好"，而是**"你凭什么这么说"**。

## 这一环要回答什么

**凭什么说它变好了。** 听起来是个配角问题，实际上它是这条链上**最稀缺的资源**：

- 模型能力不够，可以加数据、加算力、换架构——都有路径。
- 评测没有判别力，则**所有上游改进都失去意义**：你分不清是真的变好了，还是评测被绕过了。

所以这一环的两个块，一个讲"样本量不够时你测不出差别"，另一个讲"样本量够了基准本身也能被绕开"。

## 智驾侧的评测

| 手段 | 特点 |
|---|---|
| 里程 / 接管率（MPI） | 行业通用口径，但需要海量里程才能测出小差异，且长尾事件极稀疏 |
| **影子模式** | 新模型部署在量产车上**只推理、不控制**，与人类驾驶员的行为对比。以零风险获得真实分布上的评测数据 `!CITE` |
| 仿真回放 | 可重复、可造边角场景，但存在 sim-to-real 差距 |

**影子模式是智驾独有的优势**，它直接得益于"数据边际成本≈0"这个成本结构：车队本来就在跑，顺带评测几乎不增加成本。**具身没有对应的手段**——你不可能让一万台机器人在真实世界里"只推理不控制"地积累评测数据。

## 具身侧的评测

- **任务成功率**是通用口径，但方差极大：同样的策略换个初始位姿就可能从 90% 掉到 40%。
- **基准**：LIBERO 系列（仿真操作）、SimplerEnv（真机对齐的仿真）、以及各家自建的评测集。
- **核心困难**：任务空间太大、单次评测太贵、环境和硬件的差异让跨实验室结果难以比较。

## 这一环已收敛的统计规范

**不要自己设计评测方法**，这一层有成熟的统计学工具：

- **样本量与置信区间**：报告成功率必须带区间。用 Wilson 区间而不是正态近似（小样本、接近 0/1 时更稳）。（→ ⑥-01）
- **扰动划分**：把标准基准任务做系统性扰动（换场景、换物体、换初始条件），用来区分"学会了"和"记住了"。（→ ⑥-02）
- **配对比较**：同一批初始条件下对比两个策略，比各自独立跑再比均值有效得多——因为消掉了初始条件这个最大的方差来源。
- **分层 bootstrap**：按任务/场景分层重采样，避免某个简单任务主导置信区间。
- **预注册与双盲**：评测指标在看到结果之前定死；条件允许时让评测者不知道跑的是哪个策略。

**这一环的规范程度被严重低估。** 机器学习顶会近年的可复现性危机，很大程度上就是这些规范没有被采用。
