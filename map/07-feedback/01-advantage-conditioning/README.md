# 优势条件化与过滤的代价

> 环 ⑦ 回流 · 层级 **主** · 证据 `self`

## 直观

这个领域最硬的约束不是算力，是数据。算力可以买，模型可以变大，数据不行：采一条真机示范要占一个操作员、一台机器、一块场地和一段时间。自动驾驶那边正好相反——车在路上跑本身就在产数据，边际采集成本趋近于零 `!CITE`。把两边的单位数据成本放在一起，差的不是几倍，是两个数量级以上 `!CITE`。

所以真问题不是"怎么多采"，是"怎么让已经采到的每一条更值钱"。最朴素的做法是**一视同仁**：每条示范都是最大似然里的一个样本，权重都是 1。行为克隆的默认设置就是这样。

但这个假设站不住。一条磕磕绊绊、最后勉强成功的轨迹，和一条一次过的干净轨迹，不该同等对待；一条失败的轨迹，也不该被默认当成零信息。

麻烦在于，一旦开始区别对待，就会踩到一个陷阱。失败不是随机分布的——它集中在难的地方。你按"成功"过滤，等于**把最难的那一段场景优先删掉**。在训练集上这会显得更好看；到了真需要它工作的那一段，策略手里一点证据都没有，只能从很远的地方外推过去。这一块就是把这件事量出来：同一个数据池，四种用法，在两个分布上各考一次。

## 机制

一条**场景轴** s ∈ [0, 1]，它同时就是难度。干净示范在该场景执行的动作是 a\*(s) = sin(πs)。数据池不是均匀铺在场景轴上的——采集发生在便宜的地方，场景密度按 (1 - s) 递减。

关键的结构假设是**难度天花板**：s 到 0.75 之前成功率线性降到零，0.75 之上**每一次尝试都失败**。下面所有结论都挂在这一条上：天花板之上，一条失败的示范是那个场景唯一的证据。

每条示范带一个隐变量**质量分** q：成功落在 [0.75, 1]，失败落在 [0, 0.15]——两段刻意不重叠，这样"只留成功"就等于"按优势符号硬过滤"。执行出来的动作偏离专家动作 (1 - q) × (0.35 + 0.15·噪声)：越糟的示范，既越偏、又越抖。

打分的是一个 **critic**，而且它打的分**带噪**：Â = A + 0.4·η。任何假设价值函数完美的加权结论，都不是关于真实系统的结论，所以本块还额外报了一组"用真值代替 critic"的对照。

**策略是从数据里这么学的**：一个加权核回归（Nadaraya–Watson）——某个场景上的动作，取它附近示范动作的加权平均，核宽固定 0.06。就这一行，没有拟合，确定性。选它是因为它把两种失效模式摆到明面上：坏示范把均值拖偏（偏差），被滤掉的示范留下一个洞、核只能从很远的地方填（覆盖）。

四种用法只差一个权重向量：

| 策略 | 权重 |
|---|---|
| 全用 | w = 1 |
| 只留成功 | w = 1[critic 判成功] |
| 优势加权 | w = exp(Â / β) |
| 加权+保底 | w = max(exp(Â / β), ε) |

200 条示范 × 40 个副本。两个评估分布：**训练分布**按数据池自身的场景密度加权；**偏移分布**均匀铺在 [0.7, 1]——硬的那一段，也正好是天花板之后。

| 策略 | 有效样本占比 | 训练分布 RMSE | 偏移分布 RMSE |
|---|---|---|---|
| 全用 | 100.0 | 0.1936 | 0.4084 |
| 只留成功 | 55.0 | **0.154** | 0.5762 |
| 优势加权 β=0.4 | 21.2 | **0.1253** | 0.4048 |
| 加权+保底 ε=0.005 | 22.2 | 0.1308 | **0.4017** |

**一、只留成功在两个分布上给出相反的答案。** 训练分布上它是 0.154，比"全用"的 0.1936 好 1.26 倍——这就是为什么过滤看起来是个好主意，你在自己的验证集上只会看到这一半。偏移分布上它是 0.5762，比"全用"差 1.41 倍，而且比"什么都不学、直接输出数据池均值"的常数预测器（0.43692）还差。**过滤不是"少学一点"，它是在最需要它的地方主动做错。** 有效样本那一列说了原因：过滤还留着 55.0% 的样本，但这 55% 的分布已经不对了——留下来的几乎全是容易场景。

**二、优势加权是唯一两个分布上都不输的策略。** 训练分布 0.1253（比"全用"好 1.545 倍），偏移分布 0.4048（和"全用"的 0.4084 打平，比值 1.009）。

但它的偏移分布表现**不是 advantage 的功劳**。把加权后的核质量拆开看：在最难的那个评估点上，落在天花板之上（全部失败）的示范占了 **99.9%** 的核质量，而离它最近的**成功**示范在 5.66 个核宽之外。也就是说，即使 exp(Â / β) 把每条失败示范的权重压到万分之一，核的局部性仍然让它们赢——因为远处的成功示范在核里衰减得更狠。**advantage 让它在数据密的地方敢狠，核的局部性替它在数据稀的地方保了底。**

**三、加权强度有拐点，而过头的代价是双向的。**

| β | 有效样本占比 | 训练分布 RMSE | 偏移分布 RMSE |
|---|---|---|---|
| 0.05 | 0.87 | 0.2259 | 0.5676 |
| 0.1 | 1.53 | 0.1731 | 0.4977 |
| 0.2 | 4.95 | 0.1329 | 0.4266 |
| 0.4 | 21.2 | **0.1253** | **0.4048** |
| 0.8 | 51.1 | 0.1396 | 0.4053 |
| 2.0 | 84.5 | 0.1655 | 0.4072 |

β 是加权的温度，越小越狠。**β=0.05 时有效样本只剩 0.87%：训练分布 0.2259，比"全用"还差 1.167 倍；偏移分布 0.5676，比最优 β 差 1.402 倍。** 这就是那个拐点，而且比预想的硬——加权太狠不是"偏移分布上亏一点"，是训练分布也一起做坏了。

右半边几乎是平的：β 从 0.4 到 2.0，偏移分布只从 0.4048 动到 0.4072，"全用"的 0.4084 就趴在这个平台上。**这条轴上做错的代价是不对称的——加得太狠会掉下去，加得太软只是回到原点。**

**四、一个负结果：把坏数据加回来，这次没帮上忙。**

| ε | 有效样本占比 | 训练分布 RMSE | 偏移分布 RMSE |
|---|---|---|---|
| 0 | 21.2 | 0.1253 | 0.4048 |
| 0.001 | 21.3 | 0.1258 | 0.4043 |
| 0.005 | 22.2 | 0.1308 | **0.4017** |
| 0.02 | 27.2 | 0.1472 | 0.4046 |
| 0.1 | 62.5 | 0.1782 | 0.4078 |

保底 ε 是"每条示范至少保留多少权重"。扫过去，偏移分布最好的一档只比不保底赢 **1.008 倍**，训练分布则单调变差（0.1253 → 0.1782）。这个负结果是**设定**造成的，不是方法本身被判死：在核回归里，失败数据的价值已经被核的局部性兑现了（见结论二那组 99.9%），保底只是在不需要它们的地方又加了一遍。要让保底重新变得值得，得让失败示范的偏差异质——有些失败其实离成功很近——本块的 q 把失败压在 [0, 0.15] 这个窄带里，等于把这个可能性关掉了。

最后把 critic 单独拎出来对照。同样一个"只留成功"的硬过滤，用真值判断是 0.5434，用 critic 的估计判断是 0.5762，差 1.06 倍。**在这个设定里，过滤得准不准只是二阶效应，决定成败的是要不要过滤。**

## 边界

- **这是模型，不是真实的策略训练。** "策略"就是一个加权核回归估计器，可解释、确定性、参数为零。它复现的是数据选择这件事的偏差-方差结构，不是 RECAP 或 AWR 的任何具体数字。
- **难度天花板是本块的承重墙。** 0.75 之上成功率被设成**恰好为零**。这是"失败数据有价值"的唯一来源。如果天花板之上仍然偶尔成功，过滤的代价会小得多——把成功率下限调上去，结论一就会明显减弱。这一条不是测出来的，是设定的。
- **优势是外生给定的。** 零均值高斯噪声，真实的 critic 要自己训，误差有偏、且与状态相关，这里没建模。
- **核宽固定 0.06，这对结论二至关重要。** 本块里优势加权的偏移分布表现靠的是核的局部性，不是 advantage 本身。真实的策略网络没有这种硬局部性，在数据空洞处它倾向于外推到一个自信但错误的值，而不是退回近邻。**结论二的方向可以迁移，倍数不能。**
- **"训练分布"是数据池自身的场景分布**，按分位数重采样得出，不是均匀分布。这个选择是有意的：过滤的收益在你自己的验证集上就是能看见，本块不想把这个事实藏起来。
- **失败示范的动作偏差是常数**，与场景无关。换成异质偏差，或者把 q 的失败带放宽，结论四会反转。
- 两个倍数是这组常数（200 条、40 副本、一个核宽）的产物，方向不依赖常数，数值依赖。

## 脉络

链条走完一圈：① 的数据约定决定别人能不能用你的数据 → ② 的表征决定同一批数据能喂出什么 → ③④⑤ 把它变成一个能在真机上按时跑动的策略 → ⑥ 判断它到底行不行 → ⑦ 把它变成下一轮的数据。

闭环里**最贵的一段是 ⑦ 的入口**：每条真机示范都要真金白银，这段成本不会随规模下降。**最稀缺的一段是 ⑥**：⑥-01 说样本量不够、⑥-02 说样本量够了基准也能被绕开——判别力比数据更稀缺。

而 ⑦ 干的这件事，恰好是**拿最稀缺的那一样去省最贵的那一样**：用一个可靠的价值判断，决定哪条数据值得学。所以优势条件化的上限不由加权公式决定，由 critic 的质量决定；而 critic 的质量又只能靠 ⑥ 来判。闭环在这里合上：**回流环的输出是下一轮的数据，它的输入是这一轮的评估。**
