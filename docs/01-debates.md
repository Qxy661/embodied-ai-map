# 还没有定论的地方

> 一个只讲"已收敛结论"的综述会给人错误的确定感。这一页记录的是**真实的路线之争**——两边都有工业界在做，都还没被说服。

这些争论不单独成块，因为它们的共同特征是：**还没有工程上的裁判**。

## 一、端到端还是模块化

**这一条两边都在摆，而且没停。**

端到端的理由：模块间接口是信息瓶颈，误差逐段累积，手工设计的中间表示（框、轨迹）丢掉的信息无法找回。

模块化的理由：可解释、可单独验证、可局部修复、可加规则兜底。**在安全攸关的场景里，"出错时能定位到哪一段"不是锦上添花，是准入条件。**

目前的状态不是某一方获胜，而是**按风险分层**：智驾在低速/封闭场景推端到端，在量产上仍保留规则兜底；具身因为不涉及公共安全，端到端走得更远。

**判断这条轴往哪摆，看的是"出错代价"而不是"技术先进性"。**

## 二、连续生成还是离散 token

③-02（流匹配）与 ③-03（AR token）讲了两条路线。取舍是清楚的：

| | 流匹配 / 扩散 | AR token |
|---|---|---|
| 输出 | 连续、无量化误差 | 离散、误差有下界（≈ 行程/2N） |
| 解码 | 少步并行（10 步量级） | 多步串行（每步依赖上一步） |
| 基建 | 需要自己的采样器 | 复用 LLM 全套（KV cache、teacher forcing） |
| 多模态 | 天然多峰 | 天然多峰 |

**真正的分歧不在精度，在基建复用。** 如果语言模型的能力继续沿 token 路线增长，那么"动作也是 token"能白拿这些进展；如果连续生成方法在效率上继续拉开差距，token 化的量化误差就成了纯粹的成本。

**目前没有裁判**，因为两边都还没有在同一个大规模数据+算力条件下被公平比较过。

## 三、显式几何还是学习式表征

② 环里提到：智驾必须落到一个共享几何空间（因为有地图和规控要对接），具身可以把空间交给模型自己学。

**具身内部也没定**：点云/深度精度高但传感器贵、标定难、在反光与透明物体上失效；纯 RGB 便宜、泛化好，但空间精度要靠模型学，而这恰恰是最需要精确的地方。

**这一条最终大概率由传感器成本决定，而不是由算法决定。**

## 四、模仿学习还是强化学习

模仿学习（行为克隆）稳定、简单、数据利用率高，但**受限于示范的质量和覆盖**——它学不会示范里没有的行为。

强化学习能超越示范，但样本效率低到在真机上往往不可行，且 reward 设计本身是个难题。

**当前工业界主流是模仿学习打底、用 ⑦ 环的优势加权往 RL 靠**——这个折中之所以流行，不是因为它更优，而是因为真机采样的成本不允许纯 RL。

**这一条是数据成本结构（① 环）的直接后果，不是算法偏好。**

## 五、规模还是效率

智驾敢上十亿参数端到端，具身普遍用几 B 的 VLA。这不是具身界更"聪明"，是**数据成本不允许**。

但这条也在动：如果合成数据、世界模型、跨本体迁移能压低数据成本，具身的规模上限会跟着抬。**所以这条轴的走向，取决于 ① 环的成本能不能降下来**——而不是取决于谁先做出更大的模型。

---

## 怎么用这一页

看到有人声称某条路线"已经赢了"，先回到这里对一下：

- 这个结论是在**什么成本结构**下成立的？
- 换一个数据成本、换一个出错代价，它还成立吗？
- 它是在**同一个规模条件下**比较出来的吗？

本图的三条跨域收敛（分层架构、动作生成范式的同步演化、数据成本结构的分野）之所以值得当成结论，恰恰是因为它们**在不同团队、不同成本结构下都出现过**。这一页的这些争论之所以还是争论，恰恰是因为它们没有。
