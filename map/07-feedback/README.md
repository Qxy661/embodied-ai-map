# ⑦ 回流

> 最后一环，但它指向第一环。**这张图不是一个流程，是一个环。**

## 这一环要回答什么

数据 → 表征 → 决策 → 执行 → 部署 → 评估，然后呢？

评估的产出不能只是"这个模型多少分"，它必须**变成下一轮的数据**。这一环就是那个回程。

## 回流的两种形态

**形态一：把评估信号变成数据权重。** 一次 rollout 里，不是所有时刻都同样值得学。成功的、平滑的、没有犹豫的片段价值更高；失败片段也不是全无价值——它标出了策略的边界。**优势条件化**（advantage conditioning）就是给每条数据按"比平均水平好多少"加权，而不是一视同仁地做最大似然。（→ ⑦-01）

**形态二：把部署变成采集。** 智驾的影子模式（→ ⑥）本质上是这一环的前半段：车队在跑，模型在旁听，有价值的分歧被自动捞出来进训练集。**这条路径的边际成本≈0，是智驾数据优势的直接体现。**

## 具身这一环的困难

具身缺乏"免费采集"的路径，所以回流必须靠人工设计：

- **遥操作**：人示范正确动作，成本高但质量可控。
- **人工干预**：策略执行时人接管，接管前后的状态对是极有价值的纠错信号（DAgger 一派的思路）。`!CITE`
- **成功后筛选**：只保留成功的 episode 做行为克隆，简单有效，但会造成分布偏移——剩下的都是"容易"的场景（→ ⑦-01 会把这个权衡量化）。
- **仿真补数据**：便宜，但 sim-to-real 差距要么靠域随机化硬扛，要么靠真实数据对齐。

## 闭环里最贵和最稀缺的两段

回到这张图的整体：

| | 最贵的一段 | 最稀缺的一段 |
|---|---|---|
| **智驾** | 长尾场景的真实里程（但车队顺带采集，边际成本≈0） | 有判别力的评测 |
| **具身** | **真实数据的采集本身** | **同样是有判别力的评测，且更贵** |

**结论是同一个：这一整条链上，瓶颈不在模型，在数据成本和评测判别力。**

这个结论也解释了为什么本图把 ⑦ 放在最后却不当作收尾——**它是 ① 的输入**。数据成本决定了能采多少，评测判别力决定了采得对不对，两者共同决定了下一轮模型的上限。
