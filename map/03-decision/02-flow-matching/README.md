# 流匹配：从噪声到动作块的向量场

> 环 ③ 决策 · 层级 **主** · 证据 `self`

## 直观

两堆沙子，一堆在左，一堆在右，中间空着。从正中撒一把新沙子，再要求每一粒都滚到最近的那堆上——这件事本身就是矛盾的：你手里只有位置，没有"这粒本该属于哪堆"。

流匹配换了个问法。它不问"这粒属于哪堆"，而问"站在这个位置上，该往哪个方向走"。训练时答案现成：我们知道每一粒是从哪出发（噪声）、又落在哪（数据），所以正确的箭头就是终点减去起点。让一个网络把这个差值拟合出来，就得到一张铺满全平面的箭头表。

采样是照表走：从噪声点出发，沿箭头走一小步，看一眼新位置的箭头，再走一步。走十几步，人就站在沙堆上了。整件事只需要一个小网络和十几行代码——本块想说的第一件事就是，里面没有魔法。

要小心的是另外两件事。箭头必须和走路的方向配套：教反了，走得越多离得越远。步数也不能太少：太少了网络只会把你送到两堆沙子正中间那片空地上，而且它送得理直气壮。

## 机制

动作分布用二维双峰高斯当最小模型：两簇中心在 (1.5, 0) 和 (-1.5, 0)，标准差 0.35，等权。真实动作块是高维张量，这里把维数压到 2 只是为了能把它想清楚——多模态、两簇等权、簇内高斯，这三点才是要害。

本块用的约定是**噪声在 τ=0、数据在 τ=1**：

```
τ = 0 是噪声，τ = 1 是数据
x_τ = τ·x1 + (1 - τ)·x0        x1 ~ 数据,  x0 ~ N(0, I)
u = d x_τ / d τ = x1 - x0       ← 要拟合的目标向量场
采样：x ← x + δ·v_θ(x, τ)        δ = 1 / 步数,  τ 从 0 走到 1
```

时间轴往哪边摆是自由的，两条都有人用：把噪声放在 t=1，目标场就写成 `u = ε - A`，积分时步长取负；把噪声放在 τ=0，目标场就是 `x1 - x0`，积分时步长取正。两个写法互为时间反演，各自都自洽——**但符号和积分方向必须一起搬**。这一点在下面第一小节里用实验钉死。 !CITE

模型是 3 层 MLP：`[x, y, τ]` → 64 → 64 → 2，4546 个参数。前向和反向传播全部手写（反向就是十几行链式法则，代码里拿数值梯度校验过，最大相对误差 4.6e-08），Adam 2000 步，batch 256，学习率 0.001，每档统计量用 4096 个样本估计。

### 一、符号消融（头号结果）

同一个种子、同一批数据、同样的 2000 步，只换目标场的符号，训练两个模型。两者的拟合质量几乎相同（训练 MSE 1.421 对 1.419）——它们都很认真地学会了被要求学的东西，差别只在要求本身。

| 目标场 | 积分方向 | 到最近簇中心距离 | 覆盖率 |
|---|---|---|---|
| `u = x1 - x0` | τ: 0 → 1 | 0.422 | 95.7% |
| `u = x0 - x1` | τ: 0 → 1 | 2.618 | 5.9% |

差 6.2 倍，而且两个方向的走势完全对称：正确版随步数收敛（1 步 1.329 → 50 步 0.421），取反版随步数**单调远离数据**（1 步 2.078 → 50 步 2.693，涨 1.3 倍）。步数越多，正确的越对，错的越错。

取反版到底走到哪去了？目标场取反等价于沿同一条直线路径朝反方向积分：τ 从 0 退到 −1，那一端的边际分布是 `-x1 + 2x0`，它到最近簇中心的平均距离是 2.244。学出来的场在训练区间之外只能外推，实际停在 2.693，比解析值还远一点。所以它不是"数值爆炸"，是**朝数据的反方向走了**——走到比纯噪声（1.260）还散的地方去了。

这里要说准的是：**单看符号没有对错，符号和积分方向是一对，必须一起搬。** π0 那一系把噪声放在 t=1，正文写的 `u = ε - A` 就是那条时间轴的导数，配 `dt` 取负的采样循环，自洽。 !CITE

**这不是本块推演出来的假想风险——参考实现自己就为此留了一条注释。** openpi 的 `src/openpi/models/pi0.py`，在采样函数里，紧挨着 `dt` 那行的正上方： !CITE

> note that we use the convention more common in diffusion literature, where t=1 is noise and t=0 is the target distribution. yes, this is the opposite of the pi0 paper, and I'm sorry. !CITE

一个官方实现需要为"和自家论文符号相反"写一句道歉，说明这个坑在真实代码库里是活着的。 !CITE

危险就发生在跨约定抄公式：把它的符号原样搬进本块这条反过来的时间轴（τ 从 0 涨到 1，步长取正），就是你刚看到的 2.618。这不是笔误级别的细节——同样的网络、同样的数据、同样的训练预算，只因为这一个负号，输出从"落在动作上"变成"飞到数据外面"。

### 二、步数扫描

| 步数 | 到最近簇中心距离 | 落在两簇上 | 未覆盖 | 样本模长 | 取反版距离 |
|---|---|---|---|---|---|
| 1 | 1.329 | 4.9% | 95.1% | 0.240 | 2.078 |
| 2 | 0.645 | 80.6% | 19.4% | 0.921 | 2.304 |
| 5 | 0.437 | 93.8% | 6.2% | 1.289 | 2.490 |
| 10 | 0.422 | 95.7% | 4.3% | 1.386 | 2.618 |
| 20 | 0.413 | 96.7% | 3.3% | 1.442 | 2.636 |
| 50 | 0.421 | 97.0% | 3.0% | 1.459 | 2.693 |

先给两把尺子。数据本身到最近簇中心的平均距离是 0.431，样本模长 1.535，覆盖率 98.1%（半径 1.0 的圆装不下簇的尾巴）；纯噪声到最近簇中心 1.260，覆盖率 32.1%。

**一步不是采样器，是回归器。** 1 步时样本模长只有 0.240，几乎全挤在两簇正中间，覆盖率 4.9%——比什么都不做（纯噪声 32.1%）还差得多。原因很直白：τ=0 时 x_τ 里不含任何关于 x1 的信息，条件均值就是 0，而一步法只能输出条件均值。到 2 步才把质量推到簇上（80.6%），这一步的跨度是整张表里最大的。

**5 步之后距离就基本不动了，覆盖率到 10 步才追上来。** 距离 5 步 0.437、10 步 0.422、20 步 0.413、50 步 0.421；10 步到 50 步的比值是 0.997——多算 5 倍，什么也没换来。10 步的 0.422 已经只有数据自身 0.431 的 97.9%，覆盖率 95.7% 也达到了数据上限 98.1% 的 97.6%。剩下的差距不是模型误差，是簇本身的宽度。这就是 π0 取 10 步的理由：它踩在饱和点上，再少模式就塌，再多只是白烧推理时间。

### 三、L2 回归对照

同一张网络、同一批数据、同样 2000 步预算，只把目标换成直接回归 x1，并把 τ 钉在 0——回归策略没有迭代，只有一次机会。

它的输出几乎是常数：每轴标准差 0.045，模长 0.068，只有数据模长 1.535 的 4.4%。**4096 个样本没有一个落在任何一簇上（覆盖率 0%），到最近簇中心平均 1.435**，也就是两簇正中间那片空地。它的训练 MSE 1.283 还比流匹配的 1.421 更低——它学得很好，只是它学会的东西（条件均值）根本不是有效的动作。这正是"多模态动作分布上不能用 L2 回归"的全部论证。

## 边界

- **只在"两簇分得很开、等权、簇内高斯"时干净。** 两簇靠近、权重悬殊或簇本身是弯的，学到的场会在模式之间糊掉，此时扫描表里的甜点位置会移动甚至消失。本块证明的是机制，不是这组数字的普适性。
- **路径和求解器都定死了。** 直线插值（rectified flow 那一类）+ 一阶欧拉。换成扩散的余弦调度、或换成高阶求解器，甜点会移动；本块只说明"存在甜点、量级在十步"，不说明 10 是普适常数。
- **网络没有条件输入。** 真机上 `v_θ` 还要吃图像和语言，条件越丰富、学到的场越不平滑，步数甜点可能右移。这里的 10 步是下界性质的参照，不是产品参数。
- **"符号错了"这句话要说准。** 实验证明的是符号与积分方向必须配套；它不能证明哪篇论文写错了——把噪声放在 t=1 的写法里 `u = ε - A` 是对的。会出事的是跨约定抄公式，而这件事在代码里比在论文里更容易发生：`x1 - x0` 和 `x0 - x1` 长得太像，训练还能正常收敛（两个模型的 MSE 只差 1.421 对 1.419）。
- **覆盖率阈值是人为选的。** 判定半径 1.0 大约是簇标准差 0.35 的三倍。换阈值所有覆盖率数字都会变，结论方向不变。
- **每档只有 4096 个样本。** 表中相邻两档的覆盖率差别多数落在采样噪声里（20 步 96.7% 与 50 步 97.0% 尤其不要当成趋势）；距离那一列才是有分辨力的。
