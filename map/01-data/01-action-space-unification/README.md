# 统一动作空间：跨本体预训练的前提

> 环 ① 数据 · 层级 **主** · 证据 `self`

## 直观

三台机械臂站在同一张桌子前，做的是同一件事：看见目标往右偏了，就把末端挪过去。可它们说三种话。A 用弧度描述关节，B 用归一化读数，C 的关节论米也论厘米——同一个动作，三台机器人写出来的数字能差出几十倍。

策略网络只认数字。拿 A 的数据训出来的策略喂给 B，它输出的量级还是 A 的量级，B 收到一条大到离谱的关节指令。这不是网络容量的问题，也不是数据量的问题：策略忠实学到了「A 的数字」这层壳，没学到「这件事该怎么做」。

跨本体预训练的第一道坎因此不在模型里，而在数据进模型之前：**先把不同本体的动作翻译成同一种表示**。翻译规则本身很朴素——每个关节按自己的行程缩到同一个区间，关节少的机器人空出来的维度填零，并挂一个「这一维无效」的标记，让补出来的位置不参与训练。

下面把不翻译的代价量出来。同一个任务、同一批观测，一次用原始单位、一次用统一单位，各训一个线性策略，都在 A 上学、在 B 上考。第二组实验把同一件事换算成自回归动作头的词表大小。

## 机制

三台机器人共用一个语义任务：观测是目标相对当前末端的位移 (dx, dy, dz)，动作是让末端挪过去的关节指令。每台机器人的真值映射都是一个**各不相同**的已知线性算子（模拟「各家的运动学不同」），再叠一层动作噪声。原始空间与统一空间只差一步：后者先把每台机器人的动作按各自关节行程 min-max 归一化到 [-1, 1]，补零到最大维度，并带一个有效性掩码——掩码保证补出来的维度不参与拟合。

| 机器人 | 手臂关节 | 总维度 | 动作单位 | 关节范围 | 夹爪范围 |
|---|---|---|---|---|---|
| A | 6 | 7 | 弧度 | -3.14 ~ 3.14 | 0 ~ 1 |
| B | 7 | 8 | 归一化 | -1 ~ 1 | 0 ~ 1000 |
| C | 3 | 4 | 米 / 厘米混用 | -0.3 ~ 0.3 ／ -20 ~ 20 ／ -0.1 ~ 0.1 | 0 ~ 100 |

策略是最小二乘的线性映射：观测拼一列常数当 X，W 解 `min ‖XW - Y‖²`。每台机器人各 4000 对样本，六种迁移顺序全跑。**误差一律换算到被迁移方的原始动作单位上统计**，且只统计两台机器人共有的纯手臂关节维——夹爪在三台机器人里落在第 7、8、4 维，索引本来就对不齐，这一条留给语义对齐去解决，这里先排除，免得把两件事混在一起。

| 迁移 | 共有维 | 原始空间 MAE | 统一空间 MAE | 降低 |
|---|---|---|---|---|
| A → B | 6 | 0.5576 | 0.035 | 15.9 倍 |
| A → C | 3 | 2.12 | 0.23 | 9.2 倍 |
| B → A | 6 | 0.56 | 0.11 | 5.1 倍 |
| B → C | 3 | 1.97 | 0.21 | 9.4 倍 |
| C → A | 3 | 2.12 | 0.12 | 17.4 倍 |
| C → B | 3 | 1.97 | 0.033 | 59.2 倍 |

（两列 MAE 的单位是各自被迁移方的动作单位，所以只能横着比倍数，不能竖着比大小。）

三个结论：

**一、不做统一，A 学到的策略在 B 上平均错 0.5576。** B 的手臂关节整个行程才 [-1, 1]——这个误差相当于每次都把关节往行程的角落里推。根因就是单位：A 的关节是弧度，同一个位移在 A 那边写出来是 B 的 3.14 倍。跨本体迁移失败的根因在这儿，不在网络容量。

**二、统一之后剩下的 0.035，已经贴到噪声地板上了。** 单看目标本身的动作噪声，均值 0.02 的高斯平均绝对值就是 0.016；再把三台机器人**真的不同**的那部分运动学差异（Δ = 0.08）算进去，理论残差正好落在 0.035 这个量级。也就是说，统一动作空间几乎把「约定不同」造成的误差全部消掉了，剩下的那点就是「本体确实不同」。

**三、词表大小从「按本体数增长」变成「按最大自由度增长」。** 每维离散成 256 档。原始空间里每台机器人各有一套 bins：7 + 8 + 4 = 19 维 × 256 = 4864。统一空间共享一套 bins：8 维 × 256 = 2048。压缩比 2.375。本体越多、自由度越杂，这个比值越大——这就是「跨本体难共享 DoF 词表」那个论断的定量版本。

最后把 Δ 扫一遍，看统一空间的优势靠什么撑着：

| 运动学差异 Δ | 原始空间 MAE | 统一空间 MAE | 降低 |
|---|---|---|---|
| 0.00 | 0.55 | 0.016 | 34.8 倍 |
| 0.02 | 0.55 | 0.018 | 31.2 倍 |
| 0.05 | 0.56 | 0.025 | 22.1 倍 |
| 0.08 | 0.56 | 0.035 | 15.9 倍 |
| 0.15 | 0.57 | 0.061 | 9.4 倍 |
| 0.30 | 0.60 | 0.12 | 5.1 倍 |

Δ = 0 时残差 0.016 正好等于纯噪声的平均绝对值——归一化把两台机器人变成了**同一个函数**。Δ 越大优势被吃得越快，但即便 Δ 大到 0.30（同一维上的运动学差异达到行程的三成），统一空间仍然好 5.1 倍。**归一化消得掉「约定」，消不掉「本体」。**

## 边界

- **归一化参数是假设已知的。** 每个关节的行程这里直接给了真值。现实中要么去 URDF 读厂商标定，要么从数据里统计分位数——后者本身就要跨本体对齐、要处理长尾和异常值，是另一块不小的工作，它的代价没有计入上面的数字。
- **真值映射被构造成「归一化后三台机器人共享同一个算子、只差一个 Δ」。** 这正是统一动作空间想买的那个假设。它成立时上表就是收益；它不成立时（一台是臂、一台是腿，或两台机器人的同一维根本不对应同一件事），min-max 归一化一点忙都帮不上。**这张表量的是「约定不同」的代价，不是「本体不同」的代价。**
- **夹爪维和多余关节维被排除在统计之外。** 真实系统必须显式处理关节数与语义的对齐（按语义重排、掩码、补齐），省掉这一步只是为了让「单位」这一个变量干净地隔离出来。
- **用线性策略拟合线性真值是刻意选的**，它让「单位」成为唯一的差异源，结论不会被模型容量不足污染。换成非线性策略，不统一的损失只会更大，不会更小。
- **只有三台虚拟机器人、19 个自由度。** 2.375 这个压缩比是这组设定的产物，不是普适常数。

## 脉络

动作归一化把「各说各话」问题转化成「共用一套表示」问题（RT-X 那一代做的 per-dataset 归一化就是这一步）→ 有了它才谈得上拿别人的数据训自己的机器人 → 而观测侧的对齐是 ② 表征环的事。
