# 慢脑 / 快脑：分层架构的可行区间

> 环 ⑤ 部署 · 层级 **主** · 证据 `self`

## 直观

关节伺服从不停地在跑，一秒修正 1000 次。一个够大的 VLA 每前向一次要几十毫秒。把这两件事塞进同一个循环，就是让一个每 30 毫秒才说一句话的模型去当 1000 赫兹的控制器——它不是慢一点，是慢了 30 倍，而这个差距不是优化能补上的，它差在数量级上。

行业里三家独立团队给出了同一个形状：三段式的 Figure Helix、双系统的 GR00T N1、云-端分层的 Gemini Robotics 1.5。共识不是把大模型加速到 1000 赫兹——那做不到——而是**不要正面解决延迟**：让慢脑算得慢一点但算得对，让快脑用高频把慢脑的意图补成连续动作。 `!CITE`

于是问题换了个问法。不是「VLA 要跑多少赫兹」，而是「慢脑多久说一次话，才既不耽误快脑、自己又来得及算」。这个问题有答案，而且答案是一段**区间**：太慢，快脑接不住；太快，慢脑积压。中间那段才是能跑的配置。

本块把这段区间量出来，并且验证：**如果只有一层，这段区间是空的。**

## 机制

模型只有一条：**延迟预算**。

慢脑每 T 秒发布一次意图，而这条意图基于 L 秒前的观测——那是它自己前向一次所花的时间。快脑以 1000 赫兹把这条意图补成连续指令。于是快脑手里的意图总有一个「年龄」：

    t_eff = L + 0.5T

L 是慢脑的前向时间；0.5T 是一个保持周期里的平均等待——快脑得等慢脑把下一条算完，才有新信息。**这个 0.5T 是整块的关键**：它把「慢脑多慢」和「快脑跟得多紧」直接换算成了同一个量。

纯延迟作用在运动上就是跟踪误差。对频率 f 的正弦运动，延迟 t 造成的误差（对振幅的比值）恰好是 `2sin(πf·t_eff)`。两条约束从这里长出来：

- **下界来自跟踪**：T 越大，t_eff 越大，误差越大。误差撞上预算，慢脑就不能再慢了。
- **上界来自算力**：发布一次至少要花 L，所以 T ≥ L，即 f_slow ≤ 1/L。再快就是积压，慢脑的输出队列会一直涨。

两个约束夹出一段区间——**这段区间就是分层架构成立的条件**。

两种快脑策略夹住设计空间，结构上与前一块（③-01）同构：

| 策略 | 行为 | 对应现实 |
|---|---|---|
| 保持 | 拿着上一条意图不动 | 一个只会缓冲的快脑 |
| 外推 | 量出上一条斜率，往前推 | 学习型快脑的**上界** |

配置：控制环 1000 Hz，慢脑延迟 30 ms，任务运动带宽 0.5 Hz，误差预算取 RMS 不超过振幅的 30%。表格按 1 ms 控制周期量化，所以频率只能取整数个 tick 的倒数。

把采样换成整数 tick 上的二分，两条边界精确到：

| 量 | 值 |
|---|---|
| 跟踪下界（保持） | 5.263 Hz |
| 跟踪下界（外推） | 3.623 Hz |
| 算力上界 | 33.333 Hz |
| 区间（保持） | 6.333 倍宽 |
| 区间（外推） | 9.2 倍宽 |

**一、区间存在，而且两端都是硬的。** 保持型快脑下，慢脑可以落在 5.263 到 33.333 赫兹之间。下界处处可验：5.263 Hz 时误差 29.9%，周期再拉长一个控制周期就翻过 30.0%。上界同样硬：40 Hz 以上的三行跟踪误差其实更好（9.5% 一路降到 7.7%），但它们**算不动**——30 ms 的前向塞不进 25 ms 的周期。这正好是任务里那两句话的算术形式：跟得上，但算不完。

**二、误差地板是慢脑自己的延迟，不是快脑不够快。** 保持型快脑的误差从 29.412 Hz 的 10.5% 一路压到 100 Hz 的 7.7%，再往下压不动了——地板是 6.7%，那是纯延迟 L 单独贡献的。**也就是说，不管慢脑多快，只要它还慢半拍，误差就有下限。** 快脑的频率不是瓶颈，慢脑的延迟才是。

**三、快脑会不会预测，直接决定下界在哪。** 外推把下界从 5.263 Hz 推到 3.623 Hz，慢脑可以慢 1.453 倍——同一块慢脑，配一个会外推的快脑就多出一截余量。但看表格头两行：f_slow = 1.0 和 2.0 Hz 时外推反而**更差**（88.2% 对 79.3%，80.0% 对 65.2%）。斜率推得越远越发散，预测只在信息还新的时候有用。这是个诚实的负面结果，不是可以省略的细节。

**四、区间不是永久的，任务一变快就没了。** 把任务运动带宽从 0.5 Hz 往上抬：

| 任务带宽 (Hz) | 下界·保持 (Hz) | 下界·外推 (Hz) | 区间·保持 | 区间·外推 |
|---|---|---|---|---|
| 0.1 | 0.82 | 0.714 | 有 | 有 |
| 0.25 | 2.336 | 1.733 | 有 | 有 |
| 0.5 | 5.263 | 3.623 | 有 | 有 |
| 1.0 | 14.085 | 8.065 | 有 | 有 |
| 2.0 | 125.0 | 28.571 | 无 | 有 |
| 4.0 | 无 | 无 | 无 | 无 |

保持型快脑能服务的任务带宽顶到 1.502 Hz；外推型顶到 2.086 Hz（宽 1.389 倍）。过了这条线，跟踪要求的最慢频率已经超过算力允许的最快频率，两端交叉。**这就是分层的边界条件：它不是「慢脑多快」的问题，是「任务多快」的问题。**

**五、只有一层时，这段区间是空的。** 单层意味着同一个模型既出意图又闭环：它必须够快到 1000 Hz 去闭合控制环，又必须够慢到不超过 33.333 Hz 才不会积压。1000 > 33.333，无解，差 30 倍。**分层不是把延迟优化掉，是把「控制频率」和「模型频率」这两个原本绑死的量解耦。** 代价写在第五列：在 5.263 Hz 上，慢脑每说一次话，快脑要自己编出 190 个控制周期；就算跑到算力上界 33.333 Hz，也还有 30 个。慢脑的表达能力就被压到这么窄的接口上。

作为交叉验证，模拟在 9 个高频率点上与 ZOH 的闭式解最大偏差 0.001108——量级上是数值噪声，说明这条 `2sin(πf·t_eff)` 不是事后拟合。

## 边界

- **这是延迟预算模型，不是控制模型。** 没有被控对象、没有闭环、没有反馈、没有接触、没有扰动抑制。它证明的是「在这两条约束下，单层无解、分层有解」；它**不能**证明真实机器人必须分层。真实系统里让快脑必需的另一半理由——1 kHz 闭环的稳定性与抗扰——本块一个字都没碰。
- **误差预算 30% 是选的，不是导出的。** 它直接决定区间宽度：预算放松下界下移，预算收紧区间收窄甚至消失。任务带宽的顶（1.502 Hz）就是预算被延迟吃光的地方。换一个预算，所有具体数字都会变，**方向不变**。
- **两种快脑都是近似。** 保持是悲观下界，外推是乐观上界（它假设运动在两个意图之间近似线性）。真实学习型快脑落在两者之间，够不到外推那条线。
- **慢脑延迟固定 30 ms。** 真实系统里这个数随量化、批大小、编译栈变化（→ ⑤-01），而它同时是区间的上界和误差地板，所以它会整体平移区间。30 ms 取的是「几十毫秒」的下沿，偏乐观。
- **误差定义在正弦上。** 非正弦、非平稳、带切换的运动不会有这么干净的闭式，`2sin(πf·t_eff)` 那一步就不成立了。
- **二分的单调性有小瑕疵。** 保持周期和运动周期之间有拍频，误差曲线有 0.0031 量级的非单调抖动（外推 0.0055），所以二分出的边界带同量级的不确定度。边界位置另行逐点验证过：不存在比它更慢、却仍满足预算的周期。
- **引用部分是厂商公开描述，本块没有复现其中任何一个数字。** Figure 公开的慢脑频率量级 `7–9 Hz` 落在本模型区间下界（5.263 Hz）的附近，但这是**巧合还是印证，本块分不出来**——它们的延迟、任务带宽、误差预算本块都不知道。把本模型的数字反推回它们的系统，是这一步最容易犯的错。 `!CITE`
